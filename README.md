## 这是什么

**PCL 自配版**是基于 PCL2 开源版 2.99.0.0 的第三方分支，VB.NET / WPF 编写，目标框架 .NET Framework 4.8。

和官方最大的不同是：**几乎所有需要配置的东西都摊开在界面上让你自己填**——官方服务凭据、联机方式、服务端参数、
下载源、启动参数，都给出输入框与说明，而不是替你决定或者藏在配置里。它不内置任何凭据，也不假装自己"开箱即用"。

在此之上，把上游没做、或做了但容易让人误会的地方补齐：

- 官方已弃用的 EasyTier 联机换成 **陶瓦（Terracotta）**，房间码一填就能连，可与 HMCL / FCL 互通；
- 整合包导出补上**第三方启动器能认的元数据**，HMCL / Prism 直接导入；
- 新增**服务端下载、安装、开服、管理**一整条链路（原版 / Forge / NeoForge / Fabric / Folia / Purpur）；
- 几十处「界面说的和事实不一致」的修补：按钮写了能做的就真能做，做不到的提前说清。

一句话：**内核仍是 PCL2，改的是"该让你自己配的让你自己配"，外加联机、导出与服务端。**

**只基于上游开源版**，不基于 PCL CE、PCL2 社区版等其他分支；也不跟随上游版本演进——上游更新后由本分支自行取舍。

## 功能总览

### 启动

| 功能 | 说明 |
|---|---|
| 版本管理 | 多版本安装、版本隔离、模组 / 资源包 / 存档管理，PCL2 原有能力 |
| 离线登录 | 随便起用户名即可用；支持**自定义 UUID** 或按名字生成标准离线 UUID |
| 微软正版登录 | 需**自备 Client ID**（见下文「需要自己准备的东西」） |
| 外置登录 / 第三方 | 默认填好 LittleSkin，也可改成别的 Authlib-Injector 服务器 |
| 启动卡住自动重试 | 卡在「等待游戏窗口出现」时按设定超时关闭重开，默认开启 / 30 秒 / 重试 1 次，可调 |
| 实例迁移 | 版本概览里看**占用空间**，可把存档 / 设置 / 全部数据迁到另一个版本（只复制不删除） |
| 扫描其他启动器 | 识别 PCL / HMCL / **美西螈（Axolotl）** 的数据目录并转换为 PCL 结构；已转换的可重新转换（覆盖，旧副本进回收站），mods 数量对不上会提示 |
| 启动页提示 | 「你知道吗」显示功能或冷知识，可在设置里关 |

### 下载

左侧共八个分区：原版游戏、Mod、整合包、数据包、资源包、光影包、**插件**、**服务器**。

| 功能 | 说明 |
|---|---|
| 原版游戏 | 正式版 / 预览版 / 远古版 / 愚人节版分组；解除上游对原版下载的限制 |
| 模组与资源 | Mod、整合包、数据包、资源包、光影包，多来源（CurseForge / Modrinth / MCIM 镜像） |
| 插件 | Bukkit / Spigot / Paper 生态插件，填名称搜索 |
| 服务器 | **原版 / Forge / NeoForge / Fabric / Folia / Purpur** 服务端下载与安装，详见下一节 |
| 任务管理 | 所有下载进任务栏，可看进度、暂停、取消；失败自动用普通下载重试一次，再失败才报错 |
| 百宝箱 | 自定义下载：填地址直接下，自动推断文件名，地址非法当场提示；另有内存优化、垃圾清理 |

### 服务端（下载页「服务器」+ 联机页「服务器」）

这是 2026-10-31 之后新增的一整条链路，本分支与官方差别最大的一块。

**下载与安装**

- 选版本 → 选加载器（原版 / Forge / NeoForge / Fabric / Folia / Purpur）→ 开始下载；
- 原版 `server.jar`、安装器下载、静默安装**合成一个任务**，权重按耗时分配，装完即用；
- **镜像自建安装**：官方 maven（`maven.neoforged.net` / `maven.minecraftforge.net`）不可达时，
  自动解析安装器内容、从镜像下库、跑 processor 完成安装，不依赖官方仓库；
- 目录里已有 `server.jar` 会跳过重复下载；安装成功写 `server.json`（`mc` / `loader` / `loaderVer` / `updated`），
  换机或别人拷来的目录也能自报版本；
- 缺 Java 自动下载；Java 列表「清理」只删 `runtime` 下的运行时。

**开服与管理**

- 「已装服务端」下拉：**用这个开服 / 打开目录 / 删除**（删除走回收站，二次确认）；
- 首次开服按**离线优先**创建 `server.properties`（`online-mode=false`）；
- 配置项（端口 / 最大人数 / 白名单 / 正版验证 / MOTD / 难度 / 游戏模式 / 视距 / PvP）**改动即存**；
- **玩家名单 + 管理员**：勾选即 OP、取消即普通玩家；服务端在跑走控制台 `op`/`deop` 立即生效，没在跑写 `ops.json`；
  删除玩家连带撤销管理员；
- **白名单**：多行批量添加（空格 / 英文逗号 / 换行都行）、勾选删除；写 `whitelist.json` 并自动开 `white-list`；
- **实时控制台**：显示服务端输出、可发任意命令（回车发送，自动去掉前导 `/`）；JVM 与 stdin 统一 UTF-8，中文不乱码；
- **远程 RCON**：控制云服务器 / 别人机器上的服务端；连上后命令框自动走远程（看不到实时日志，只有命令回显）；
- **添加已有**：把别处装好的服务端目录登记进来；
- **关闭服务器**：stdin 发 `stop`，15 秒未退出强杀；
- **关闭启动器时**：弹窗问「让它继续跑」还是「一起关掉」，也可在设置里定成默认；重开启动器按 PID + 进程名认回遗留进程并自动连 RCON；
- **打开日志**：直接打开该服务端的 `logs\latest.log`。

### 联机

- **陶瓦（Terracotta 0.4.2）**：一键建房 / 加入，只填房间码；4 个下载源轮询 + SHA-512 校验；
  房间码本地校验（34 进制取模 7），错码不发请求；房主态自动收起「复制直连地址」（那是游客本机回环地址）。
- **加入服务器**：填 `host` / `host:port` / `[IPv6]:port`，可备注名称、勾选「启动游戏时默认进入」；
  加入时选离线登录（默认）或微软正版登录。
- 跨启动器互通范围见下文「已知限制」。

### 设置

| 项 | 说明 |
|---|---|
| 官方服务凭据 | 微软登录 Client ID；CurseForge 密钥（可选，不填走 MCIM 镜像） |
| 启动 | 启动卡住重试的开关 / 超时 / 次数 |
| 关闭启动器时一并关掉本机服务端 | 默认**不勾**（= 保留服务端继续跑）；静默退出按此设置走 |
| 卸载与清理 | 删 `PCL\` 目录、exe、`.exe.config`、`libwebp.dll` 与注册表 `HKCU\Software\PCLDebug`；两次确认，延迟执行、立即退出 |
| 本分支自动更新 | 默认关闭，不发布 Release 资产 |

## 怎么用

### 1. 准备

- Windows 10 及以上，**.NET Framework 4.8**
- 启动器**不含游戏本体**，需要自备 Minecraft 账号或离线用户名
- 想用正版登录：自备微软 Client ID 并过 Mojang AppID 审核（见下节）；不准备就用离线登录

### 2. 获取与运行

本仓库只发源码，不提供成品。两种方式：

- **自己编译**：按 [`AGENTS.md`](AGENTS.md) 准备 `_tools\`（构建工具链，未入库），在 `pcl-src\` 下跑 `build.cmd`；
  产物在 `PCL-custom\versions\<版本>\`，根目录也有 `Plain Craft Launcher 2.exe`。
- **拿自编成品**：本仓库不提供。作者自用版本的更新记录见 `CHANGELOG.md`。

放哪儿都行，配置会写在 exe 同级的 `PCL\` 目录里；**只拷 exe 到新位置等于全新配置**。

### 3. 登录

启动页点「离线登录」随便填名字即可；要正版就填好 Client ID 后选微软登录；
外置登录在登录页「第三方」里，默认 LittleSkin。

### 4. 下载并启动游戏

下载页 → 原版游戏 → 选版本（可再叠 Forge / NeoForge / Fabric）→ 开始下载 → 完成后回启动页选版本 → 启动。

### 5. 开服（本机）

1. 下载页 → **服务器** → 选版本 → 选加载器 → 开始下载；
2. 装完回**联机页 → 服务器**，在「已装服务端」选它 → **用这个开服**；
3. 配置端口 / 人数 / 白名单 / 正版验证 / MOTD，改动即存；
4. 把地址发给朋友（同一局域网用内网 IP，跨公网用穿透工具或陶瓦）；
5. 关服点「关闭服务器」；关启动器时会问是否保留服务端。

### 6. 联机（陶瓦）

双方都开陶瓦 → 房主建房拿到房间码 → 游客填房间码加入。跨公网与 HMCL / FCL 可互通，与 PCL CE 只限同一局域网（见下表）。

### 7. 导出整合包

实例 → 导出 → 勾选「额外写入 MCBBS v2 元数据」，导出的包在 HMCL / Prism / 原版 PCL 都能直接导入。

### 8. 卸载

设置 → 其他 → **卸载与清理**（两次确认后删除程序文件与注册表项，游戏数据与 `PCL\` 配置目录按提示自行处理）。

## 需要自己准备的东西

本仓库**不内置任何官方服务凭据**。上游开源版已把这两处字段清空，按微软应用条款也不能转用他人（包括官方 PCL）的 Client ID。

| 项 | 是否必需 | 说明 |
|---|---|---|
| **微软登录 Client ID** | 只在使用正版登录时需要 | 到 Microsoft Entra 注册应用，**再向 Mojang 申请 AppID 审核**。两步都过才能登录，只做第一步最后会被 403 拒绝。步骤见启动器内「帮助 → 指南 → 微软正版登录」 |
| **CurseForge 密钥** | 不需要 | 不填时请求自动走 MCIM 镜像（`mod.mcimirror.top`），密钥由镜像代付；代价是刚发布的文件可能要等同步 |

填法：**设置 → 其他 →「官方服务凭据」→ 微软登录 Client ID**，保存后重启启动器生效。

## 已知限制

这些不是待修项，是当前环境的客观边界，写在这里避免误判成故障。

**联机互通范围**（最容易被误会的一条）：

| 对方 | 同一局域网 | 跨公网 |
|---|---|---|
| 本启动器 ↔ 本启动器 | ✅ | ✅ |
| 本启动器 ↔ HMCL / FCL / ZL2 等（直接内置陶瓦） | ✅ | ✅ |
| 本启动器 ↔ **PCL CE** | ✅ 实测通过（延迟 9 ms） | ❌ **不通** |

PCL CE 不直接跑陶瓦，而是用它自研的 EasyTier 客户端去接陶瓦房间，那条通道固定带 `--p2p-only`（只走点对点、拒绝中继）。
同网不需要打洞所以能进；跨公网打洞失败就没有中继兜底。**卡点在对方，本分支这一侧没加这个限制。**

- **离线皮肤**：自定义皮肤以资源包本地替换，**仅自己可见**，且会替换游戏中所有角色。
- **未支持的加载器**：Quilt、Cleanroom、LegacyFabric、LabyMod 没有安装入口。
- **服务端安装器**：Forge / NeoForge 官方 maven 不可达时走镜像自建安装；安装器自身仍要直连官方仓库，失败会提示开加速器或用镜像路线。

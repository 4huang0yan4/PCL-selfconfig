## 这是什么

**PCL 自配版**是 [Plain Craft Launcher 2](https://github.com/Meloong-Git/PCL) 开源版 **2.99.0.0**
的第三方分支，用 VB.NET / WPF 写的 Minecraft 启动器，目标框架 .NET Framework 4.8。

作者日常用 PCL2 玩 Minecraft，有两件事上游没做、或做了但容易让人误会，于是直接改源码：
① 官方已弃用的 EasyTier 联机换成 **陶瓦联机（Terracotta）**，房间码一填就能连，并能与
HMCL / FCL 这类同样内置陶瓦的启动器互通；② 整合包导出补上 **第三方启动器能认的元数据**，
导出的包在 HMCL、Prism 里都能直接导入。其余改动是几十处「界面说的和事实不一致」的修补——
按钮写了能做的事就真能做，做不到的提前说清，不靠兜底逻辑篡改用户刚做的选择。

一句话：**内核仍是 PCL2，改的是联机与导出，其余是把话说准。**

**只基于上游开源版**，不基于 PCL CE、PCL2 社区版等其他分支；也不跟随上游版本演进——
上游更新后由本分支自行取舍，不保证与任何上游版本行为一致。

## 主要特点（速览）

| 方面 | 本分支做了什么 |
|---|---|
| **联机** | 移除官方已弃用的 EasyTier，换成**陶瓦（Terracotta）**：房间码一填就连，可与 HMCL / FCL 等同样内置陶瓦的启动器互通 |
| **整合包导出** | 加一个「额外写入 MCBBS v2 元数据」开关，导出的包在 **HMCL / Prism / 原版 PCL** 都能直接导入（Forge / NeoForge / Fabric 三端实测全通） |
| **下载** | 解除官方对原版下载的限制；百宝箱带「自定义下载」，填地址就下，地址非法当场提示而不是下载途中失败 |
| **启动** | 卡在「等待游戏窗口出现」时自动重试（默认超时 30 秒、重试 1 次，可在设置里调） |
| **一致性** | 几十处「界面说的和事实不一致」的修补：按钮写了能做的就真能做，做不到的提前说清，不用兜底逻辑篡改用户刚做的选择 |

## 需要自己准备的两样东西

本仓库**不内置任何官方服务凭据**。上游开源版已把这两处字段清空，而按微软应用条款也不能转用他人（包括官方 PCL）的 Client ID。

| 项 | 是否必需 | 说明 |
|---|---|---|
| **微软登录 Client ID** | 只在使用正版登录时需要 | 到 Microsoft Entra 自己注册应用，**再向 Mojang 申请 AppID 审核**。两步都过才能登录，只做第一步会在最后一步被 403 拒绝。步骤见启动器内「帮助 → 指南 → 微软正版登录」 |
| **CurseForge 密钥** | 不需要 | 不填时请求自动走 MCIM 镜像（`mod.mcimirror.top`），密钥由镜像代付；代价是刚发布的文件可能要等同步 |

**不填微软 Client ID 也能正常用**：启动页选「离线登录」，随便起个用户名即可，只是进不了正版验证的服务器。

拿到 Client ID 后填在 **设置 → 其他 →「官方服务凭据」→ 微软登录 Client ID**，保存会重启启动器后生效。

## 主要特性

### 联机：换成陶瓦

官方自带的 EasyTier 联机在这个分支里被移除，替换为 **陶瓦联机（Terracotta）**。

- **一键建房 / 加入**，只填房间码，不需要手动配隧道
- **自动安装**：4 个下载源轮询 + SHA-512 校验 + 解压，装完即用
- **房间码本地校验**（34 进制取模 7，与陶瓦解析一致），错码不发请求
- **房主态自动收起「复制直连地址」**——那是游客本机的回环地址（`127.0.0.1`），房主根本没有可发给别人的直连地址，留着只会让人以为功能坏了
- **跨启动器互通**：与 HMCL / FCL 等内置陶瓦的启动器可跨公网直连；
  与 **PCL CE 只在同一局域网内能通，跨公网不行**（原因见「已知限制」里的范围表）

### 整合包导出：能被第三方启动器认

新增高级选项「**额外写入 MCBBS v2 元数据**」，勾选后在包根写入 `mcbbs.packmeta` 与 `manifest.json`，原 PCL 格式内容不变。

实测结果：

| 目标 | Forge | NeoForge | Fabric |
|---|---|---|---|
| PCL | ✅ | ✅ | ✅ |
| HMCL 3.15.2 | ✅ | ✅ | ✅ |
| Prism | ✅ | ✅ | ✅ |

同时修掉了一个隐蔽缺陷：包内原先无条件写入 `modrinth.index.json`，导致三种元数据混装，HMCL 会优先按 Modrinth 解析、再按 `dependencies` 去下载对应加载器，版本对不上就整包导入失败——而真正正确的 `mcbbs.packmeta` 反而读不到。现在只在**不勾 MCBBS** 时才写它。

### 百宝箱

- **自定义下载**：填下载地址直接下，自动从末段推断文件名，可指定保存位置；地址非法当场提示，不在下载途中失败
- **内存优化** / **垃圾清理**

### 启动

- **启动卡住时自动重试**：有些客户端（模组整合包、自定义窗口标题、反作弊拦截）会让启动器一直认不出游戏窗口，界面停在「等待游戏窗口出现」。开启后按设定超时关闭并重开，默认**开启 / 超时 30 秒 / 最多重试 1 次**，可在「设置 → 启动」调整
- **启动页「你知道吗」提示**：显示启动器功能或 Minecraft 冷知识，可在设置里关闭

## 使用前提

- Windows 10 及以上，.NET Framework 4.8
- 启动器**不含游戏本体**，需要自备 Minecraft
- 联机要求双方陶瓦版本一致（当前 0.4.2）
- **正版登录需自备 Azure Client ID 并通过 Mojang AppID 审核**，详见上文「需要自己准备的两样东西」；未准备时用离线登录

## 已知限制

这些不是待修项，是当前环境的客观边界，写在这里避免误判成故障：

**联机互通范围**（最容易被误会的一条，先看这张表）：

| 对方 | 同一局域网 / 同一网络 | 跨公网 |
|---|---|---|
| 本启动器 ↔ 本启动器 | ✅ | ✅ |
| 本启动器 ↔ HMCL / FCL / ZL2 等（直接内置陶瓦） | ✅ | ✅ |
| 本启动器 ↔ **PCL CE** | ✅ 实测通过（延迟 9 ms） | ❌ **不通** |

**PCL CE 为什么只能同网**：它不直接跑陶瓦，而是用它自研的 EasyTier 客户端去接陶瓦房间，那条 EasyTier 固定带 `--p2p-only`（只走点对点、拒绝中继）。同一网络内根本不需要打洞，所以能进；一旦跨公网、打洞失败，就没有中继可以兜底。**本分支这一侧没有加这个限制，卡点在对方。**

确实要跨网连 CE，只能改用第三方穿透工具（樱花等），能连但延迟不保证。

**离线皮肤**：自定义皮肤以资源包方式本地替换，**仅自己可见**，而且会替换游戏中所有角色。想让别人看到需要皮肤站 + 外置登录，或装皮肤模组。

**未支持的加载器**：Quilt、Cleanroom、LegacyFabric、LabyMod 都没有安装入口。

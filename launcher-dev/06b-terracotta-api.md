## 四、HTTP API 全表（全部是 GET，可直接浏览器打开）

| 路径 | 作用 | 返回 |
|---|---|---|
| `GET /state` | 读当前状态 | 状态 JSON，见第五节 |
| `GET /` | 同 `/state`（同一处理函数） | 同上 |
| `GET /state/scanning?room=&player=&public_nodes=` | **建房**：扫描本机局域网世界并开房 | 200（异步，状态转 `host-scanning`） |
| `GET /state/guesting?room=<房间码>&player=&public_nodes=` | **加入**：校验码合法且当前空闲则 200 | 200 / **400**（码非法或状态非空闲） |
| `GET /state/ide` | **复位到 waiting**（名字叫 ide，实际是 reset） | 200 |
| `GET /meta` | 版本信息 | `version` / `easytier_version` / `yggdrasil_port` / `target_*` |
| `GET /log?fetch=true` | 下载运行日志（排错用） | 文件流 |
| `GET /panic?peaceful=true` | 关闭陶瓦 | **无响应**，直接进程退出（连接被重置属正常） |

可选参数：`room` 建房时留空则由陶瓦随机生成房间码；`player` 是显示名；`public_nodes` 可指定自定义公共节点（v0.4.2 新增）。

## 七、房间码格式（做前端校验用）

```
U/XXXX-XXXX-XXXX-XXXX        共 21 字符（U、/、16 位、3 个连字符）
```

- 字符表 **34 个**：`0123456789ABCDEFGHJKLMNPQRSTUVWXYZ`（去掉了易混的 `I` 和 `O`）
- 解析时 `I` 归一为 `1`、`O` 归一为 `0`，大小写不敏感
- **校验位规则**：把 16 位按 34 进制转成整数，必须能被 **7** 整除，否则判定非法
- 合法示例：`U/D8P6-1PM5-ZQEQ-EYY8`（本机实测生成）
- 注意：`U/0000-0000-0000-0000` 是**合法**的（0 能被 7 整除），做测试用例时要改末位

建房时 `room` 留空 = 随机生成；也可指定固定码（同码即同房间，用错会撞房）。

## 九、坑（全部实测或读源码确认）

1. **本地回环请求会被系统代理劫持** —— 本机 `HTTP_PROXY` 存在时，`curl http://127.0.0.1:<port>/state` 返回 **502**（代理返回的）。PCL 的 `Netlib` 若走系统代理，同样会失败。**必须对 127.0.0.1 显式禁用代理**。
2. **`VCRUNTIME140.DLL` 必须与 exe 同目录** —— 包里就两个文件，只拷 exe 会启动失败。
3. **`/panic` 不回响应** —— 直接 `process::exit(0)`，客户端会收到连接重置，属正常，不要当错误。
4. **`host-scanning` 无超时** —— 没开局域网会永久停在这一步（实测），必须自己做超时提示与取消。
5. **同机不能既当房主又当游客** —— 全局文件锁使一台机器只有一个守护进程和一份状态。
6. **状态是全机共享的** —— 若用户同时开 HMCL 和 PCL，两边看到的是同一份状态；在 PCL 里复位会影响 HMCL 的界面。集成时不要在 `waiting` 之外擅自杀进程。
7. **锁文件会残留** —— 崩溃后 `terracotta.lock` 仍在（本次实测残留了 53344）。必须 `GET /meta` 探活，不能只凭文件存在判断。
8. **同机多个局域网世界会歧义** —— 扫描器取 `get_ports().first()`，若同时开两个世界的局域网，可能连错世界。建议 UI 提示"只开一个世界"。
9. **版本不一致直接失败** —— v0.4.2 移除了对 TerracottaLegacy 与 PCL2CE 旧房间格式的支持；房主与游客必须都在 ≥0.4.2。
10. **`easytier` 公共节点依赖外网** —— 首次组网要拉公共节点，网络受限时会停在 `host-starting` 或落到 `exception`。

## 十、许可与合规

AGPL-3.0 例外条款原文（`README.md`）：

> 1. 您的程序通过打包的方式包含本作品未经修改的二进制形式，而没有静态或动态地链接到本作品；或
> 2. 您的程序通过本作品提供的进程间通信接口（如 HTTP API）与未经修改的本作品应用程序进行交互，
>    且在您的程序用户界面明显处标识了本作品的版权信息。

本项目的做法**同时满足第 1、2 条**：原样打包官方二进制（不改） + 只经 HTTP API 通信。
若将来改为公开分发，需在联机页面显著位置写明"联机功能由 Terracotta 提供"并给出仓库链接。

**当前定调是不发布**（见 `01-scope.md`），因此无义务；上述标注仍建议做，成本为零。
